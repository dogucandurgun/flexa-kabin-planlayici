# FLEXA Kabin Planlayıcı

FLEXA modüler kabinleri için 3D planlayıcı (ön tasarım). Statik bir sitedir; kurulum gerektirmez.

Yerelde açmak için bu klasörde bir statik sunucu çalıştırın, örneğin `python3 -m http.server 4180`, ardından http://127.0.0.1:4180 adresine gidin.

Three.js, kendi MIT lisansıyla dağıtılır; bkz. `vendor/LICENSE`.
